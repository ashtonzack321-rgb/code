# ServerScriptService

`Main.server.lua` starts the services in `Services/`. See `game/README.md` for what each one does.
The remaining services from `Roblox Research/My Game/Systems and Scripts.md` (CycleService,
HerdService, AlphaService, LassoService, TowService, CombatService, BreedingService, EventService,
MarketService) are added here as they are built.

The map is not built by a server script. Build it once in Studio from the Command Bar
(see `game/README.md`), then save the place.
