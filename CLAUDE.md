# Project memory

This repo is the user's Obsidian vault for Roblox game research and development.

- The vault is `Roblox Research/`. Start with `Roblox Research/00 Index.md`.
- Read the relevant notes before answering questions about Roblox games, design, UI, scripting or monetization.
- Save new research as Obsidian notes: YAML frontmatter, `[[wikilinks]]` between notes, images in `Attachments/`.
  - Games go in `Games/`, cross-game analysis in `Concepts/`.
  - Link every new note from `00 Index.md`.
- Commit and push changes so the user's Obsidian (synced via the Obsidian Git plugin) picks them up.
