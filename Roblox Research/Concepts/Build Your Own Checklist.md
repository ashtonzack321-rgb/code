# Build Your Own Checklist

## MVP (weeks 1–2)
- [ ] Choose a theme with an IP hook (trend, meme, animal type) that isn't Brainrot or Egg
- [ ] Choose **one new verb** (fish, dig, tame, break, lasso...)
- [ ] Plot assignment and base slots
- [ ] Unit config table and weighted spawner
- [ ] Income tick and HUD cash counter with K/M/B formatting
- [ ] Steal, carry, deliver, return-on-hit
- [ ] Base lock timer
- [ ] ProfileStore saving and offline earnings

## Polish (weeks 3–4)
- [ ] Hatch/reveal animation and rarity colours
- [ ] Theft alerts, floating numbers and sounds
- [ ] Rebirth system (10+ tiers)
- [ ] Index/collection book
- [ ] Mobile UI pass

## Launch
- [ ] 3 gamepasses and 3 dev products, with odds shown
- [ ] Group reward
- [ ] Thumbnail: avatar + hero object + giant $/s number
- [ ] Small server size (6–8)
- [ ] Plan the first 4 weekly updates and an admin-abuse event
